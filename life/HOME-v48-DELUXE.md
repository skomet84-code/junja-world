# 준자마을 v48 DELUXE — 디테일·그래픽·모바일 조작 품질 업데이트
2026-10-19 KST

## 구현
이번 업데이트는 v48의 새 방/가구 수를 늘리거나 재화를 무한히 찍는 업데이트가 **아닙니다**. 기존 3D 인테리어를 모바일에서도 부드럽고 고급스럽게 이용하도록 실제 사용 품질을 개선합니다.

### 시각적 디테일
- 거실·공방·갤러리·로열룸 각자의 3D 색채(바닥·벽·러그·금속 장식·창틀).
- 실내 온화한 색 온도의 태양광·간접광, 입체 벽 몰딩, 이중 바닥, 목재 이음새, 그림 액자·창틀·커튼·벽등, 바닥 그림자와 가구별 세부 형태 강화.
- 소파 다리·쿠션, 원목 식탁 상판, 조명 갓, 피아노 키보드, 벽난로 불꽃, 수조 장식, 하프 줄, 황금 왕좌 장식, 샹들리에 광택 등 디테일 증가.
- 실제 동적 그림자 맵 대신 값싼 밀착 그림자 가짜 메시를 선택하여 모바일 GPU를 보호; WebGL 컨텍스트는 이전과 같이 방당 1개만 사용합니다.

### 모바일·카메라
- 3D **가구 모형 자체**를 터치해도 슬롯 선택이 가능하고, 기존 바닥 슬롯/HTML 9칸 UI는 유지합니다.
- 손가락 좌우 드래그로 카메라 방향 회전. 드래그는 구매/배치를 절대 실행하지 않습니다.
- 화면에 **좌측 회전 / 우측 회전 / 축소 / 확대 / 정면 복귀** 5개의 최소 44px 터치 영역(320/390/430px 검증).
- 렌더링에 변화가 없는 동안 매 프레임 3D를 다시 그리지 않습니다(요청 시 프레임 갱신). 가구를 **선택하는 것만으로 WebGL 컨텍스트를 끊거나 다시 만들지 않습니다**.
- 320px 좁은 폰에서 가구 카드 가독성, 툴바, 금장 테두리/패널 음영과 상태 시인성 개선. WebGL 미지원 시 HTML 배치 메뉴를 유지합니다.

## 안정성/경제
- 48 기존 가격·확률 없음·희귀도·집 레벨 해금 조건·소유권·배치 좌표·저장 클라우드 포맷 변경 없음.
- 기존 이동속도 +7.9%, 기존 v47 행동력과 서버 장부 및 원본 계정의 레벨·XP·골드 스냅샷 변경 없음.
- 이번 스테이징 그래픽 개선은 원본 운영 서버/DB에 배포하지 않습니다. 레벨 초기화(1/5) 이슈는 별도로 검증해야 합니다.
