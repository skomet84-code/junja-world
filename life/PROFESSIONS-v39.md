# JUNJA VILLAGE v39 — 직업 전문화와 일일 계약 (서버 경제 시험판)
2026-10-19 KST

## 이번 버전에서 실제 구현한 내용
- 3개 직업: 🌿 농부(작물 수확), 🥧 요리사(가공품 제작), 🏪 상인(주민 상점 거래 또는 NPC 판매)
- 첫 면허 250G, 7일 이후 직업 변경 1,200G (모두 **별도 서버 경제 시험 골드**).
- 실제 서버 장부에 기록된 수확/제작/판매/거래가 각각 직업 경력이 됩니다.
- 마일스톤: 수습 0XP, 숙련 120XP, 전문가 600XP, 명장 2,400XP, 전설 10,000XP.
- 플레이어는 **한 번에 1개 직업만 활성화**하며, 변경 시 이전 직업의 경력은 보존됩니다.
- 한국 시간 기준 하루 1회 직업 계약. 서버 거래 이력으로 목표를 증명해야 보상 지급.
- 농부: 수확 4회 (160G), 요리사: 가공 2회 (240G), 상인: 주민 상점 판매 1회 또는 NPC 판매 5회 (200G).
- 일일 수입은 계정당 1회만 지급하며, 직업을 바꿔 중복 청구하지 못하게 제한.
- 골드 지급·직업/일일 보상 기록·서버 영수증·v37 상태 스냅샷을 한 DB 트랜잭션으로 저장.
- 중복요청 UUID 재전송은 기존 영수증만 반환. 악의적인 변조와 다른 요청 UUID의 중복 수령 거부.
- 별도 UI: 개인 농장 > **직업 성장·일일 계약**.

## 데이터와 안전성
- 기존 `village_saves`, `village_wallets`, 운영 유저 경험치/레벨/재고는 변경하지 않습니다.
- v36 실험 서버 계정의 JSON state.profession에 보관하므로 별도 SQL 테이블/마이그레이션 불필요.
- v36 서버 경제 영수증 `village_economy_v36_events`의 실제 DB 기록만 경력·미션 인정.
- 직업 등록 이전 행동은 직업 경력에 반영하지 않음. 직업을 바꿀 때 지난 활동 점수는 경력에 누적하고 새 직업 시작 시점을 갱신.
- 서버 시간으로 날짜/쿨다운 판단. 클라이언트가 목표 횟수·골드·보상을 직접 전달해도 사용하지 않음.
- `ENABLE_VILLAGE_PROFESSIONS_V39=true`를 운영 환경에 설정하지 않는 한 API는 503. **기본 OFF**.
- 운영 DB와 분리된 독립 CI 데이터베이스에서만 실제 직업 보상 트랜잭션 테스트.
