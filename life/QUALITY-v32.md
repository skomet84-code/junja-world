# 준자마을 품질 개선 v32 — 2026-10-18

## 구현
- 마을과 사냥터에 동일한 서버 버전 기반 저장 큐 적용. 사냥터의 버전 누락 저장과 기기 시각 기준 로드 제거.
- 브라우저 저장소 차단/JSON 손상과 무관하게 서버 프로필 복원.
- 전송 중 변경은 순서대로 저장하고, 응답 유실 재시도는 동일 요청 ID/본문으로 처리. 서버는 동일 요청의 중복 기록을 방지.
- 마을↔사냥터 이동 전 저장 확인. 실패하면 이동을 중단하고 상태 표시.
- 계정별 일일 백업 분리. 서버 계정에 적용되지 않던 파일 복원 버튼을 비활성화하고 안내 수정.
- 가방에 실제 용량을 차지하던 물약 표시. 가방이 가득 차면 가방/판매 메뉴 열기.
- 가방 용량 HUD, 주변 채집·대화·시설 행동 버튼, 생활 수첩의 채집→제작→판매 바로가기.
- 모바일 하단 메뉴 가로 스크롤, 패널/카드/버튼 시각 통일 및 키보드 포커스.
- 나무의 미세한 움직임, 목적지 표시 애니메이션, 재료별 3D 채집 입자. 동작 줄이기 설정 지원.
- 새 모듈 빌드 포함 및 JS 캐시 재검증.

## 검증
- `npm test --prefix life`: 저장 회귀 테스트와 기존 로직 테스트 통과.
- `npm run build --prefix life`: 브라우저 자산 24개 생성.
- API 저장 테스트는 실제 핸들러에 메모리 SQL 어댑터를 연결하며 운영 DB를 사용하지 않음.
- 기존 의상 테스트의 정확히 100개 제한은 현재 141개 카탈로그에 맞춰 원래 수량 이상/전체 ID 유일성 검사로 변경.
- 실제 브라우저/아이폰 WebGL 시각 검증은 미실시. 기존 브라우저 테스트는 현재 로그인 방식에 대한 fixture 정비가 별도 필요.
- Vercel 프로젝트 조회는 연결 계정 scope 403으로 차단됨. 운영 배포 완료를 확인하지 못함.
