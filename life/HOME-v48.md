# JUNJA VILLAGE v48 — 시그니처 주택·3D 방별 인테리어·희귀 가구·이동속도 미세 상향
작성: 2026-10-19 KST

## 기능

### 개인 주택과 방별 3D 인테리어
- 기존 홈 메뉴와 농장 메뉴에서 **v48 나의 집 스튜디오**를 열 수 있습니다. 기존 캐릭터의 홈 레벨(1~4), 집 돌보기, 벽지, 집 증축, 기본 가구 구매·보상은 유지합니다.
- 주택 Lv1은 거실 1개, Lv2는 거실+공방 2개, Lv3 갤러리, Lv4 로열룸 총 4개.
- 각 방은 9칸의 실제 Three.js 미니어처 3D 내부. 바닥의 슬롯이나 하단 슬롯 버튼을 눌러 위치를 지정. 가구 교환/재배치 **무료**.
- 기존 'sofa','table','lamp','plant','cat','piano' 가구는 각 방의 빈 칸으로 **자동 논리 마이그레이션**(단지 표시될 때 계산). 기존 재산을 삭제하거나 같은 아이템을 다시 구매하도록 강요하지 않음.
- 신규 가구: 희귀 벽난로, 장인의 책장; 영웅 심해 수조·달빛 하프; 전설 왕실 황금 의자·별빛 샹들리에. 기존 일반 가구와 피아노도 같은 스튜디오에서 정가를 볼 수 있음.
- 레벨 조건이 있는 확정가 아이템이며 확률형 추첨 또는 현금 결제, 보너스 골드 수령이 없습니다.
- 인테리어 **명성 수집 점수**는 외형·소유 목표 용도. 매일 들어오는 무료 골드·경험치 보상은 새로 만들지 않았습니다.
- 본 게임의 기존 'spend'와 'save' 연결을 통해 홈 인테리어 구매/배치 후 클라우드 저장 큐로 이어집니다. 슬롯 배치는 현재 계정의 `home.decorV48` 기록에 포함됩니다.
- 주택 2/3/4단계로 성장하면 본 마을의 3D 집 외관도 차양·화단 → 발코니 → 로열 지붕 장식 순으로 개선됨. 건물의 원래 충돌 박스는 바꾸지 않았습니다.

### 조금만 더 빠른 걷기
- 기본 마을 길찾기·터치 걷기: **190 → 205 월드 단위/초 (+7.89%)**.
- 키보드 조작: 동일 205를 사용하여 입력 방식별 속도차를 막았습니다.
- 개인 3D 농장 걷기: **260 → 280 단위/초 (+7.69%)**.
- 기존 swept collision, 경로 목적지 판정, arrival callback, 미끄러짐 방지 카메라는 그대로 두었습니다. **달리기·속도 강화 아이템 도입은 하지 않았습니다.**

## 안전·테스트
- `home-interiors-v48.js`: 순수 상품 규칙, legacy 소유 복원, 방·슬롯 충돌/교환, prestige (게임 프로필 골드/레벨 변경 없음).
- `home-room-3d-v48.js`: 3D 가구 12종 미니어처 모델·레이캐스팅. 하나의 실내 컨텍스트만 열고, 모달 종료/화면 전환 시 `dispose()`와 `forceContextLoss()`로 GPU 자원을 놓아줍니다. WebGL이 불가하면 9칸 HTML 버튼으로 계속 배치할 수 있습니다.
- `home-studio-ui-v48.js`: 모바일 가구 상점·방 선택·수집점수·기존 구매/저장 위임.
- `test_home_interiors_v48.mjs`: 기존 인벤토리 무변경, 가격·등급·레벨, 중복 소유 방지, room swap 원자성, 손상된 좌표 복구, 이동속도 +7.9%.
- `test_home_mobile_v48.mjs`: 실제 Chromium 320/390/430 폭에서 게임의 기존 홈 메뉴부터 새 스튜디오 진입, 3D 화면, 가구 공방·희귀 왕좌 구입, 방별 슬롯 이동, 구입 횟수 1회, 이전 피아노·테이블 보존, 모바일 오버플로·JS 오류 점검. 로컬 테스트 전용 가짜 지갑 사용하여 실제 계정에서 차감하지 않습니다.
- 기존 저장 보호 회귀테스트(v32~v47), Vercel 웹 빌드 유지.

## 구분과 출고 조건
- 원본 유저 레벨/골드 자동 초기화 문제가 완전히 해결됐다고 주장하지 않습니다. 클라우드 저장 API 차단(수정 시 레벨 잃을 위험) 기능도 해제하지 않습니다.
- 원래 하우징 구매는 기존 게임의 **클라이언트 기반 골드**를 사용합니다. v36~v47 시험 서버 경제(G)와 혼합되지 않으며, 보안 강화 전에 서로 이전하지 않습니다.
- 공식 `junja-village-friends` 서버/사용자 DB는 이번 버전에서 미수정. 우선 격리된 `junja-village-v42-staging` 프로젝트에서 검증하고, iOS Safari·장시간 플레이·2명 이상 재접속/저장 보존 검사 후 운영 반영 검토.
- 새 주택 룸/배치용 별도 SQL 마이그레이션 필요 없음. 기존 `home` JSON 저장에 `decorV48` 선택 필드만 추가됩니다.
