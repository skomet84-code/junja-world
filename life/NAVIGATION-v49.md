# JUNJA VILLAGE v49 — 메뉴 구조/동선 대정리 (모바일+PC)
2026-10-19 KST

## 바뀐 플레이어 메뉴
하단 기존 '옷장·농사·낚시·제작·꾸미기·가방·성장 수첩·내 농장' 8칸을 **홈·생활·생산·집·가방**의 5칸으로 바꿉니다.
- **홈:** 현재 저장 기록에서 계산한 생활 목표/진행률/보상, 실제 해당 장소로 가는 CTA, 돈 버는 3단계 '농장 → 제작소 → 주문 납품', 자주 쓰는 6개 메뉴.
- **생활:** 내 농장, 낚시(부두로 걷기), 채집(숲으로 걷기), 오늘의 일일 미션, 직업/계약(시험), 사냥터, 축제·주간 의뢰, 친구와 소통.
- **생산:** 제작소(마을 공방으로 걷기), 주민 주문, 나의 사업장(시험), 3D 사업장 거리(시험), 판매 상점, 주민 거래소(시험).
- **집:** 3D 인테리어·희귀 가구, 마을 꾸미기, 옷장, 어항 컬렉션, 명예 기록.
- **가방:** 가방/용량, 수확 창고, 재료 판매, 마을 지도, 계정 저장 보관함.

### 친구들이 길을 잃지 않도록
- 어디 있는지 몰라도 **'기능 검색'에 '낚시/주문/집/사업장'**을 입력하면 현재 분류와 바로가기 버튼이 뜹니다. 별도 네트워크 요청이나 저장 불필요.
- '제작소로 이동', '낚시(부두로 이동)', '채집(숲으로 이동)'처럼 **실제 위치 도착이 필요한 기능을 명시**. 거리 제한 무시/텔레포트/레벨 우회는 하지 않습니다.
- 버튼 이름은 게임 내에서 간결하게 통일. v34/v37/v38/v39/v40/v41/v46/v48 같은 **개발 버전 코드**는 플레이어 메뉴, 직업·사업장·집·거래소의 제목에서 제거(파일명/API 경로와 CI는 유지).
- 농장 안에 길게 쌓이던 7개 개발형 버튼은 **나의 공간 / 생산·직업·거래** 두 그룹의 동일 스타일 격자로 정리. 서버 경제의 안전장치/복구 장부는 삭제하지 않고 **'시험 경제·복구 기능'** 펼침으로 이동.
- 정식 레벨과 시험 경제 G가 혼동되지 않도록 관련 버튼과 서브 화면에 **'시험'** 표시 유지.
- 축제·사냥·친구 말풍선은 사라지지 않으며 각각 생활 메뉴 안에서 찾을 수 있습니다.

## UX·접근성
- 모바일 320/390/430px + PC 1280px에서 동일한 5개 메뉴 분류, 클릭 가능한 면적 최소 44px, 노치 안전 영역, 균등 폭의 카드 UI.
- 홈/생활/생산/집/가방 진입은 팝업 하나에서, 기능 목록에는 아이콘+짧은 이름+행동 설명이 붙습니다.
- 목표 진행률은 현재 게임 상태에서만 계산해 보여주고, 기존 챕터 완료/보상 지급/걸음·경로·건물 상호작용 로직 그대로 이용합니다.
- 기존 하단 8개 버튼은 **화면에서만 숨기고 DOM ID와 이벤트/모듈은 보존**하여 기존 테스트/레거시 진입점이 부서지지 않도록 합니다.
- 새 메뉴는 게임 프로필/골드/아이템/레벨/직업/행동력을 전혀 쓰지 않습니다.
