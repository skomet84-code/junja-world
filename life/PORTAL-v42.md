# 준자마을 v42 — 본마을 ↔ 3D 주민 사업장 거리 연결
2026-10-19 (KST)

## 실제 구현
- 3,600×2,400 본마을 동쪽 지역에 **'🏘️ 주민 사업장 거리' 입구 건물**과 조명 장식, 동쪽 산책로 추가.
- 새 본마을 이동 목적지: `business_district`. 메인 마을 길찾기/지도의 목적지 선택/건물 터치/근처 상호작용 공통 경로로 입장 가능.
- 건물 메시와 실제 충돌 영역은 `life/district-portal-v42.js`에 명시; 걷기 도착점(2765,1265)은 벽 충돌 밖에 있음.
- 문 앞까지 도착해야 입장 가능. 원거리에서 문을 눌러도 자동으로 길을 찾아 걷고, 도착 후 기존 v41 3D 사업장 구역을 엶.
- 방문자의 실제 게임 캐릭터 의상·헤어·모자 상태가 3D 사업장에 적용됨 (동일 Avatar3D 기반).
- `← 준자마을로 돌아가기`를 누르면 모달/3D 렌더러를 정리하고 마을 월드로 복귀. 마을 플레이어 위치는 **메모리에서만 유지하며, 포털 이동을 위해 DB나 저장 포맷을 수정하지 않음**.
- 3D 사업장 화면 동안 별도 메인 월드 렌더링 중지 (동시 프레임 비용 방지), 복귀 즉시 다시 그리기.
- 개인 농장 메뉴의 기존 v41 진입도 그대로 유지; 실험 경제 v36~v41 기능 플래그는 기본 OFF.

## 검증
- v42 길찾기 유닛 테스트: `life/test_district_portal_v42.mjs` — 마을 4개 출발지에서 실제 게임 길찾기 경로를 계산해 건물 충돌과 출입 거리 검사.
- 기존 레벨 저장 보호·농장·경제 회귀 테스트 + 브라우저 자산 빌드 GitHub Actions.
- v42 휴대폰 크기(390×844) **실제 게임 전체** E2E: `life/test_district_browser_v42.mjs` — 테스트 전용 mock 클라우드 저장 API, 메인월드 로드, 자동 걷기, 3D 사업장 열기, 원위치 복귀, 기존 골드 유지, WebGL 리소스 해제.
- 메인 월드 입장 테스트는 CI 계정/경제 API를 모두 **mock** 사용하므로 실제 사용자 계정·운영 DB 데이터를 조회하거나 수정하지 않음.

## 배포 제한/아직 미완료
- 본마을 ↔ 사업장 구역은 포털 전환이며, 이동 중 끊김 없는 단일 광역 오픈월드 로딩 방식은 아닙니다.
- 실제 iOS Safari의 정식 계정 로그인과 Neon 스테이징 계정 2명 동시 방문은 수행하지 않았습니다.
- 구역 안 다른 유저의 위치/채팅/교환 등 실시간 동기화는 v41과 동일하게 미구현.
- 기존 사용자 레벨 초기화 문제를 v42가 해결하지는 않았습니다. 이전 포털/전송으로 서버 레벨이 변경되어서도 안 됩니다.
- **운영 코드와 운영 DB에 병합/배포하지 않음**. 모든 변경은 개발 브랜치/Draft PR 검토용입니다.
- 경제와 주민 상점/사업장 추가 기능은 모두 별도 시험 지갑이며 운영 골드와 교환할 수 없습니다.
